# 🌉 SetuHub — Connecting People, Creating Impact

## 🎯 Problem Statement
In a world more connected than ever, people are feeling more **alone** than ever.  
We scroll endlessly, but rarely connect meaningfully.  
What if technology could bring us closer — *not virtually, but in reality*?

That’s why we built **SetuHub** — a bridge between people, communities, and purpose.

---

## 🚀 What is SetuHub?
**SetuHub** is a hyperlocal connection platform that helps people **connect, collaborate, and create impact** — all within their local radius.

It’s not just another app — it’s a **Setu (bridge)** that connects people when they need help, want to help, or create an impact.

---

## 🧩 Core Features

### 🆘 HelpNearBy
> "Because emergencies don’t wait for strong networks."

- Connects users with others nearby during emergencies or times of need.  
- Example: Someone stranded on a trek, or someone needing urgent help.  
- Uses **Expo Location API** for real-time location-based radius detection.  
- Makes local communities **self-reliant, responsive, and human again.**

---

### 🌱 ImpactEvents
> "One click to create real-world impact."

- Lets users organize or join local, impact-driven events — tree plantations, food drives, or charity efforts.  
- Turns **intent into action** instantly.  
- Empowers changemakers to create local impact that **ripples globally.**  
- **Tagline:** “We didn’t make an app to change the world — we made one that helps people *create change* in the world.”

---

### 📸 Moments
> "Social media that connects — not isolates."

- A social feed for **real-world participation**, not filtered selfies.  
- Encourages users to **go out, engage, and form meaningful connections.**  
- Counters loneliness and detachment caused by traditional social media.  
- Promotes positivity, purpose, and *real human presence.*

---

### 🩸 Blood Requests
> "Every drop counts."

- Facilitates urgent blood requests visible to nearby donors.  
- Supports real-time alerts using **Firebase Cloud Messaging.**  
- Helps during blood shortages and emergencies.  
- Enables community-driven responses when every second matters.

---

### 🕵️ Missing People
> "When someone disappears, the community appears."

- Platform to share and locate missing individuals using local visibility.  
- Sends geofenced alerts within relevant areas to expand the search fast.  
- A **life-saving extension** of the SetuHub network.

## ⚙️ Tech Stack

| Component | Technology |
|------------|-------------|
| **Frontend** | React Native (Expo) |
| **Backend** | Golang |
| **Database** | NeonDB (Postgres Cloud), Cloudinary |
| **Cache** | Redis |
| **Notifications** | Firebase Cloud Messaging |
| **Location Services** | Expo Location API, Google Maps Api|
| **Extra Credits** |Lottie React Native (Animations)|
> Together, this stack makes SetuHub **scalable, fast, and reliable.**
